Privacy Policy

Last updated: 2026-10-24

Caelum Files is a local file manager. It is designed to work entirely on your device.

Summary

Caelum Files does not collect, transmit, sell, or share personal data. It does not include telemetry, analytics, advertising, crash reporting, or user accounts.

Files and search

Caelum Files reads and modifies files only on the device where it is running, and only in response to actions you take. File contents, names, paths, previews, search results, hashes, and archive contents stay on your device. They are never uploaded.

Operation history and local predictions

Caelum Files keeps a short, in-session history of file operations so you can undo them. It can also learn local patterns from your recent actions to highlight likely next actions. This is a small counter-based model stored only on your device (in the app's local storage / MSIX package container). It contains no file contents, is never uploaded, and can be cleared from More → Clear Prediction Data or Settings → Local Data.

Settings, toolbar layout, and session

Settings, toolbar layout, favorites, and session state are stored locally on your device. In the Microsoft Store (MSIX) build they live in the app's package container under %LOCALAPPDATA%\Packages; in an unpackaged build they live in the app's local data directory. They are not sent anywhere. Uninstalling the app or clearing its data removes them according to the platform's normal behavior.

Network access

Caelum Files does not require a network connection for browsing, file operations, search, previews, history, or predictions. The Windows build uses the Microsoft Edge WebView2 runtime provided by the operating system to render its interface; WebView2 is a Microsoft component governed by Microsoft's terms. Caelum Files does not add third-party advertising or analytics SDKs.

Children

Caelum Files does not knowingly collect information from anyone, including children.

Changes

If this policy changes, the updated version will be published with a new "Last updated" date.

隐私政策

最后更新：2026-10-24

Caelum Files 是一款本地文件管理器，设计上完全在你的设备上工作。

概要

Caelum Files 不会收集、传输、出售或共享个人数据。它不包含遥测、统计分析、广告、崩溃上报或用户账号。

文件与搜索

Caelum Files 只在运行它的设备上读写文件，并且只响应你发起的操作。文件内容、名称、路径、预览、搜索结果、哈希值和压缩包内容都留在你的设备上，不会被上传。

操作历史与本地预测

Caelum Files 会保留一小段本次会话内的文件操作历史，用于撤销。它也可以根据你最近的操作在本机学习使用模式，用于高亮可能的下一个操作。这是一个仅保存在你设备上的小型计数模型（位于应用的本地存储 / MSIX 包容器中），不包含文件内容、从不上传，并可通过 更多 → 清除预测数据 或 设置 → 本地数据 清除。

设置、工具栏布局与会话

设置、工具栏布局、收藏和会话状态只保存在你的设备上。Microsoft Store（MSIX）版本保存在 %LOCALAPPDATA%\Packages 下的应用包容器中；未打包版本保存在应用的本地数据目录。这些数据不会发送到任何地方。卸载应用或清除其数据会按平台常规行为删除它们。

网络访问

Caelum Files 的浏览、文件操作、搜索、预览、历史和预测都不需要网络连接。Windows 版使用操作系统提供的 Microsoft Edge WebView2 运行时渲染界面；WebView2 是受 Microsoft 条款约束的 Microsoft 组件。Caelum Files 没有集成第三方广告或统计分析 SDK。

儿童

Caelum Files 不会有意收集任何人（包括儿童）的信息。

变更

如果本政策发生变化，更新后的版本会连同新的“最后更新”日期一起发布。
