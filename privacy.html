Privacy Policy

Last updated: 2026-10-30

Caelum Files is a local file manager for macOS. This policy explains what the app does with your information.

Summary

Caelum Files does not collect, transmit, sell, or share personal data. There is no account, telemetry, analytics, advertising, crash-reporting SDK, or third-party tracking. File names, paths, file contents, thumbnails, hashes, search queries, and settings stay on your Mac.

Information processed on your device

Caelum Files processes the following locally to provide its features:

  • File and folder names, paths, sizes, dates, and types.
  • File contents only when needed to open, preview, copy, move, compress, extract, hash, or rename them at your request.
  • Folder-access permissions you grant through the standard macOS folder picker. The App Store edition stores these as security-scoped bookmarks in its local preferences.
  • App settings, window layout, recent tabs, favorites, and operation history.
  • Search queries you type into the search field and help window.

This information is not sent to the developer or any third party. It is not used for tracking or advertising.

File access

The App Store edition is sandboxed. It can access its own app container, the Downloads folder permitted by the App Store sandbox entitlement, folders you explicitly add in Settings → Permissions → File Access, and items you drag into the app or choose in an open/save panel.

The direct (non-App Store) edition can access the file system subject to macOS privacy controls. Protected locations may require Full Disk Access in System Settings.

Terminal automation

“Open in Terminal” sends an Apple Event to the terminal application you choose, only after you invoke the command. macOS asks for Automation permission the first time. If you deny it, Caelum Files opens a terminal window without sending the event.

Notifications

Caelum Files can show local notifications when a file operation finishes while the app is in the background. Notifications are generated on your Mac and are not sent to a server.

Privacy manifest

The app includes PrivacyInfo.xcprivacy, which declares the required-reason APIs used for preferences, file timestamps, disk space, and system boot time. It declares no tracking and no collected data types.

Third parties

Caelum Files does not include third-party analytics, advertising, crash-reporting, or social SDKs. It does not use an account or cloud service.

Children

Caelum Files is rated 4+ and does not collect personal information from anyone, including children.

Changes

If this policy changes, the updated date above will change. Material changes will be described in the app's release notes.

隐私政策

最后更新：2026-10-30

Caelum Files 是一款本地运行的 macOS 文件管理器。本政策说明应用如何处理你的信息。

摘要

Caelum Files 不收集、不传输、不出售、不共享个人数据。应用没有账号、遥测、分析、广告、崩溃上报 SDK 或第三方追踪。文件名、路径、文件内容、缩略图、哈希、搜索词和设置都留在你的 Mac 上。

在本机处理的信息

Caelum Files 为实现功能会在本机处理：

  • 文件和文件夹的名称、路径、大小、日期和类型。
  • 仅在你要求打开、预览、复制、移动、压缩、解压、计算哈希或重命名时读取的文件内容。
  • 你通过 macOS 标准文件夹选择器授予的访问权限。App Store 版将授权保存为本地偏好设置中的 security-scoped bookmark。
  • 应用设置、窗口布局、最近标签页、收藏和操作历史。
  • 你在搜索框和帮助窗口中输入的搜索词。

这些信息不会发送给开发者或任何第三方，也不会用于追踪或广告。

文件访问

App Store 版启用沙盒，只能访问：应用自己的容器；由 App Store 沙盒 entitlement 授权的“下载”文件夹；你在设置 → 权限 → 文件访问中主动添加的文件夹；以及你拖入应用或在打开/保存面板中选择的项目临时授权。

直装版在 macOS 隐私控制范围内访问文件系统；受保护位置可能需要在系统设置中开启完全磁盘访问。

终端自动化

“在终端中打开”只在你主动执行命令后，向你选择的终端应用发送 Apple Event。macOS 首次会询问自动化权限；拒绝后 Caelum Files 会直接打开终端窗口，不发送事件。

通知

当文件操作在应用位于后台时完成，Caelum Files 可以显示本地通知。通知在本机生成，不发送到服务器。

隐私清单

应用包含 PrivacyInfo.xcprivacy，声明用于偏好设置、文件时间戳、磁盘空间和系统启动时间的 required-reason API，并声明不追踪、不收集数据类型。

第三方

Caelum Files 不包含第三方分析、广告、崩溃上报或社交 SDK，也不使用账号或云服务。

儿童

Caelum Files 年龄分级为 4+，不收集任何人的个人信息，包括儿童。

变更

政策更新时会修改上面的日期；重要变更会在版本说明中说明。
